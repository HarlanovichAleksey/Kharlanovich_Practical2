# Практическая работа №2 — Flex-модель (макет + галерея)

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Практическая работа по теме **Flex-модель**. Реализованы две задачи:
1. **Макет из 5 блоков** — раскладка через Flexbox.
2. **Галерея изображений** — адаптивная сетка из карточек с фотографиями.

## Что реализовано

### 1. Макет из 5 блоков (`layout.css`)
- Левая колонка: 3 блока вертикально (`.col-left`, `flex-direction: column`);
- Правая часть: 2 блока горизонтально (`.col-right`, `flex-direction: row`);
- Общий контейнер `.flex-layout` — Flexbox с `gap`;
- Блоки 1–3 — фиксированная высота, блоки 4–5 растягиваются через `flex: 1`.

### 2. Галерея (`gallery.css`)
- Контейнер `.gallery` — Flexbox;
- 3 колонки: узкая слева (3 маленьких картинки) и две широкие справа (по одной большой);
- Использованы `flex: 1` и `flex: 2` для пропорций колонок;
- Карточки с `border-radius`, `box-shadow`, эффектом наведения `transform: translateY(-4px)`;
- Картинки через `object-fit: cover` — заполняют блок без искажений;
- Подписи поверх картинок (`position: absolute`, полупрозрачная плашка, `backdrop-filter: blur`).

## Технологии
- HTML5
- CSS3 (Flexbox, псевдоэлементы, transitions, `backdrop-filter`)

## Файлы
- `index.html` — разметка макета и галереи;
- `style.css` — общие стили (body, контейнер, сброс);
- `layout.css` — стили макета из 5 блоков;
- `gallery.css` — стили галереи;
- `img/` — 5 изображений для галереи.
